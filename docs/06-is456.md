# 6. Code compliance — IS 456:2000

Provisions implemented when **Design code = IS 456** is selected. Basis: IS 456:2000
(Reaffirmed 2021) including Amendments 1–4, with SP 16 design aids as the verification
reference. Every clause number and numeric value below was verified against the code
text; deviations found in common secondary sources are noted.

Software action legend — **ENGINE**: internal rule of the strain-compatibility solver;
**ENFORCE**: hard input validation; **CHECK**: pass/fail row in the compliance report;
**REPORT**: informational output.

> **Load side.** Partial safety factors on loads (γf, Table 18 / Cl 36.4.1) are out of
> scope — `Pu`, `Mux`, `Muy` are entered already factored.

## 6.2 Material models

**Concrete (ENGINE):** σc = 0.446·fck·[2(ε/0.002) − (ε/0.002)²] for ε ≤ 0.002, then
0.446·fck to 0.0035; zero in tension.

**Steel (ENGINE):** Fe 250 — bilinear elastic–plastic at 0.87·fy (εyd = 0.00109).
HYSD grades — SP 16 Table A piecewise curve: linear at Es to 0.8·fyd, then knees at
inelastic strain offsets:

| Stress | 0.80·fyd | 0.85·fyd | 0.90·fyd | 0.95·fyd | 0.975·fyd | 1.00·fyd |
|---|---|---|---|---|---|---|
| Inelastic strain | 0 | 0.0001 | 0.0003 | 0.0007 | 0.0010 | 0.0020 |
| Total strain (Fe 415) | 0.00144 | 0.00163 | 0.00192 | 0.00241 | 0.00276 | 0.00380 |
| Total strain (Fe 500) | 0.00174 | 0.00195 | 0.00226 | 0.00277 | 0.00312 | 0.00417 |

Same curve in compression (symmetric). **Displaced concrete** is deducted at every
compression bar (force = As·(σs − σc)) — SP 16's own chart derivation does the same
(it uses (fsi − fci) per bar row, with a constant 0.446·fck approximation at the
pure-axial point).

## 6.3 Relationship of the rigorous check to Cl 39.6

The interaction surface generated per §5 **is** the Cl 39.5 strain-compatibility design
method extended to biaxial bending — Cl 39.6's power law is a *permitted simplified
alternative* ("Alternatively such members may be designed by…"), not an additional
obligation. The tool therefore:

1. reports the **rigorous surface utilisation** as the governing verdict;
2. computes and prints the **Cl 39.6 value** (Mux1, Muy1 from the engine's own surface
   at Pu; Puz and αn per the formulas above) because reviewers expect it;
3. flags Pu > Puz as immediate failure;
4. cross-references SP 16 (Charts 27–38 two-face, 39–50 four-face, 51–62 circular,
   Chart 63 Puz, Chart 64 biaxial contour) for library sections so users can hand-verify.
