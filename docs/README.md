# RCC Section Check — Documentation

Design documentation for the **RCC Section Check** module: biaxial axial-load–moment
interaction analysis of arbitrary reinforced-concrete sections, with clause-level
compliance to **IS 456**, **IRC 112** and the **IRS Concrete Bridge Code**.
