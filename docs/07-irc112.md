# 7. Code compliance — IRC:112-2020

Provisions implemented when **Design code = IRC 112** is selected. Basis:
**IRC:112-2020** (Code of Practice for Concrete Road Bridges). Every clause number and
value below was verified verbatim against the published 2020 text. Note that several
provisions used here are **2020-specific** — the Cl 8.2.1 assumption letters were
re-lettered from 2011, and the imperfection eccentricity (Cl 11.3.2.2), the
nominal-stiffness method (Cl 11.3.3) and the explicit εuk values (Cl 6.2.2) exist only
in the 2020 edition.

## 7.2 ULS strain limits (Cl 8.2.1, Figs 8.1/8.2)

Assumptions (a)–(k) implemented: plane sections, perfect bond, no concrete tension,
Fig 6.5 concrete stresses, Fig 6.2 steel stresses. Pivot rules:

- NA inside the section → extreme fibre at **εcu2** (pivot B) — Cl 8.2.1(j);
- pure compression → uniform strain ≤ **εc2** (pivot C) — Cl 8.2.1(h);
- NA outside the section → plane rotates about pivot C at **(1 − εc2/εcu2)·h** from the
  compressed face (= 3h/7 for fck ≤ 60) — Cl 8.2.1(i);
- inclined steel branch selected → extreme steel strain ≤ εud (pivot A) — Cl 8.2.1(f);
- box / hollow flanges under near-concentric compression (e/h < 0.1): mean strain of
  that part ≤ εc2 — Cl 8.2.1(3) (flagged for box and hollow-circular shapes).

Cl 8.2.2 / Fig 8.2 defines the five strain domains the sweep crosses.

## 7.3 Biaxial verification (Cl 8.3)

Cl 8.3.1 permits rigorous solutions observing the Cl 8.2.1 strain limits — the tool's
interaction surface is that rigorous check and governs. The **Cl 8.3.2 simplified
method** is reported alongside:

- Exemption screen (Eqs 8.1/8.2): λy/λz ≤ 2 and λz/λy ≤ 2; and relative eccentricity
  ratio ≤ 0.2, with beq = iy·√12, heq = iz·√12 for arbitrary sections. (The
  eccentricity-to-moment axis pairing is defined only in Fig 8.3 — resolved in the
  implementation per that figure.)
- Interaction (Eq 8.3): **(MEdx/MRdx)^a + (MEdy/MRdy)^a ≤ 1.0** with MEd including
  nominal second-order moments; **a = 2.0** circular/elliptical; rectangular:

  | NEd/NRd | 0.1 | 0.7 | 1.0 |
  |---|---|---|---|
  | a | 1.0 | 1.5 | 2.0 |

  linear interpolation, **NRd = Ac·fcd + As·fyd**. Below NEd/NRd = 0.1 the tool floors
  a = 1.0 (a conservative tool convention — the code tabulates only the three points).
  For T/I/L/box shapes Eq 8.3 is **not defined** — the tool reports "n/a" and the
  rigorous surface governs alone.

## 7.4 Slenderness & imperfections (input-side, Section 11)

Entered moments must already include imperfection and second-order effects:

- Slenderness screen Cl 11.2.1 Eq 11.1: λ < λlim = 20·A·B·C/√n (defaults A = 0.7,
  B = 1.1, C = 0.7), each direction (Cl 11.2.1(3)); le per Cl 11.2.2.
- Imperfection eccentricity Cl 11.3.2.2(1) (2020 only): **e_i = 15 + l0/800 ≤ 50 mm**,
  applied in the single most unfavourable direction (Cl 8.3.2(2)). **IRC 112 has no
  IS 456-style e_min = l/500 + D/30 clause**; walls use Cl 7.6.4.2 (moment ≥ 0.05·nw·h).
- Second-order moments: nominal curvature (Cl 11.3.2) or nominal stiffness
  (Cl 11.3.3.2, 2020 addition); ignorable if < 10% of first-order (Cl 11.1(5)).

## 7.7 Load-combination context

Design actions come from **IRC:6 Annex B, Table B.2** — Partial Safety Factors for
Verification of **Structural Strength**: Basic combination = column (2) (1.35 permanent;
1.75 surfacing; 1.5 leading carriageway live load; 1.15 accompanying), Accidental =
column (3), Seismic = column (4). (Table B.1 is equilibrium; B.3 serviceability; B.4
foundations.) The tool checks ULS strength only; SLS stress limits (Cl 12.2.1: σc ≤
0.48·fck; Cl 12.2.2: σs ≤ 0.8·fyk under rare combinations) are out of scope.
